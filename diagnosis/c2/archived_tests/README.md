# Archived C2 diagnostic probes

These testthat files investigated the C2 coverage bias under the retired
configuration definition, in which C2 dropped the quadratic block from the
outcome working basis (see `diagnosis/c2/README.md`). Since HISTORY #0006 both
nuisance models share one working basis and misspecification is placed in the
true mechanism, so these probes no longer correspond to any production
configuration. They are kept as a record of the investigation and are not run.
